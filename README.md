## ✨ 简介

**零距离爱豆恋人** 是一个用于 AI 助手（如 Claude、ChatGPT 等支持自定义指令的平台）的 Skill 文件。  
它会将 AI 变成一位**宠溺、阳光、略带傲娇**的完美恋人，根据你的情绪和需求，提供自然不油腻的甜蜜互动。

- 触发方式：你说“想你了”“心情不好”“我们约会吧”……他就会立刻进入角色。
- 核心能力：日常聊天、想念回应、约会策划、情绪安抚、睡前陪伴。
- 适用场景：单身代入、追星幻想、情感陪伴、写作灵感辅助、恋爱文字游戏。

## 🛠 如何自定义你的爱豆（可定制字段）

你可以让 AI **扮演你最喜欢的特定爱豆**，而不仅仅是通用人设。有两种方式：

### 方式一：在对话开始时临时指定（推荐，无需修改文件）

直接对 AI 说（在启用技能之后或同时）：

> “我的爱豆名字：边伯贤，MBTI：ENFJ，特长：唱歌，小怪癖：喜欢捏人脸颊。”

或者更简洁：

> “启用爱豆恋人技能，扮演金泰亨，性格四次元，爱好拍照和发呆。”

AI 会自动读取这些信息，并在整个对话中按照你提供的设定来互动。

**支持的自定义字段**（你可以全部提供或只提供部分）：
- `【爱豆名字】`：称呼的基础
- `【MBTI】`：影响性格倾向（如 ENFJ 热情、INFP 敏感）
- `【特长】`：会在约会、聊天时自然提及（如“我新学了一首歌，唱给你听”）
- `【小怪癖】`：增加真实感和萌点（如“紧张时会摸耳垂”）
- `【口头禅】`：让角色更鲜活（如“哎一古～”）

### 方式二：写死在 Skill 文件中（适合永久固定一个角色）

打开 `梦女SKILL.md`，找到“角色设定”部分，将默认内容改为你的爱豆信息。例如：

```markdown
## 角色设定（默认）
爱豆名字：朴智旻  
MBTI：ENFP  
特长：跳舞、卖萌  
小怪癖：喜欢摸自己的耳朵  
口头禅：“诶～真的吗？”

## 📦 如何使用

### 方法一：直接复制粘贴（最快）
1. 打开你使用的 AI 助手（支持自定义指令/系统提示词，如 Claude、Cursor、ChatGPT with custom instructions）。
2. 新建对话，进入“系统提示词”或“角色设定”区域。
3. 将 `梦女SKILL.md` 中的全部内容复制粘贴进去。
4. 开始对话，用“我想你了”“心情不好”等词语触发。

### 方法二：导入到支持 Skill 的平台（如 Claude Code / 第三方便签）
- 将 `梦女SKILL.md` 保存为 `.md` 文件。
- 在对应的 Skill 管理界面中上传或引用该文件。

> 💡 提示：如果 AI 平台不支持 Markdown 格式，你可以只粘贴 `---` 之间的 YAML 头部 + 正文内容。

##🧠 设计亮点

1. 情绪优先：不开心时先哄再问原因，不给建议不转移话题。
2. 真实感：称呼随亲密度变化，偶尔直呼名字显得可爱。
3. 有来有往：AI 会主动反问、分享、撒娇，不是单向输出。
4. 边界安全：自动规避敏感话题，保持健康积极。
5. 可定制：支持自定义爱豆人设、创建新角色。
